# Research Paper RAG

A configurable Retrieval-Augmented Generation (RAG) system for question answering over scientific PDFs.

## Features
- Multiple RAG architectures (Dense, Hybrid, Parent-Child)
- Config-driven pipeline
- Table-aware multimodal support
- Evaluation with Hit Rate@k and RAGAS

## Setup
```bash
pip install -r requirements.txt
python run_pipeline.py
